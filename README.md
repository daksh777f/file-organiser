#  File Organizer

### Automate Your File Management with Python & Web Interface

---

## 📘 Overview
The **File Organizer** is a web-based application that helps users **organize and manage their files efficiently**.  
Built using **Python, HTML, CSS, and JavaScript**, this project automates file sorting into folders based on **file types**, **extensions**, or **custom rules**, saving time and keeping your directories clean.  

The project combines the power of Python’s file handling with a **user-friendly web interface** for easy interaction.

---

## 🚀 Features
-  **Automatic File Sorting** – Sorts files into folders based on file types or extensions.  
-  **Web-Based Interface** – Clean UI built with HTML, CSS, and JavaScript.  
-  **Real-Time Feedback** – Shows progress and status of file organization.  
-  **Customizable Rules** – Users can define specific rules for organizing files.  
-  **Cross-Platform Compatible** – Works on Windows, Linux, and macOS.  

---

## 🧩 Tech Stack
| Category | Technologies Used |
|-----------|-------------------|
| **Backend** | Python 3 |
| **Frontend** | HTML5, CSS3, JavaScript |
| **Libraries** | os, shutil, pathlib, Flask (optional for web integration) |

---

## ⚙️ How It Works
1. **User Input:** The user selects the folder to organize through the web interface.  
2. **File Analysis:** Python scans the folder, identifying files and their types.  
3. **Sorting & Organization:** Files are moved into appropriate folders based on their type or predefined rules.  
4. **Status Update:** The interface shows a real-time log of organized files.  
5. **Optional Customization:** Users can define additional rules or categories for organization.
